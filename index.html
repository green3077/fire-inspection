🤖 AI 자동 인식

파일(PDF·엑셀·워드·한글·HWPX·사진)을 업로드할 때 AI가 내용을 분석해서 입력칸에 자동으로 채워줍니다. 별도 로그인/키 입력 없이 항상 동작하며, 끄면 기존 방식(자체 인식)으로만 동작합니다.

☁️ 구글 드라이브 자동 저장

업로드하는 자료(거래처 등록 파일, 지적사항 자료, 사진, 첨부파일)와 생성되는 이행완료보고서가 회사 구글 드라이브의 "조은소방_자동저장" 폴더에 현장별로 자동 저장됩니다. 별도 로그인 없이, 이 앱을 사용하는 누구의 업로드든 같은 곳에 모입니다.
